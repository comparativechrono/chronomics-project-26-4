# Third-party software, data and source provenance

This site – *Seven mutations, four hundred mammals*, the natural short sleep project of the Chronomic Medicine Group – is built from the [Bioinformatics workbench](https://github.com/comparativechrono/bioinformatics-workbench), and keeps the parts of it that the project uses. It bundles independently licensed programs and libraries, and uses others that the browser loads at run time. Each keeps its own licence: the MIT licence of the Biowasm build framework does **not** relicense the programs it compiled, and none of the licences below applies to the site's own text and code. Keep each component's notices and licence files when copying or redistributing its files.

## Command-line programs (WebAssembly, run in the browser)

These are the real programs, compiled to WebAssembly. They run on the student's own computer, inside the web page – in the Terminal and in notebook cells (`!`, `%%bash`). Each folder `assets/vendor/biowasm/NAME/VERSION/` holds the program (`.wasm`, its JavaScript loader, sometimes a `.data` file), its licence, a `NOTICE.txt` (origin and local changes) and `SHA256SUMS`. (The folder of the base module has a notice and checksums only: its licence is the Biowasm licence in `assets/vendor/biowasm/LICENSE.txt`. The four files at the top of `assets/vendor/biowasm/` – the runner, its licence and the two descriptions of the local changes – have a `SHA256SUMS` of their own there.)

Every `.wasm` file also contains parts of the Emscripten runtime and its C and C++ libraries (musl, libc++, compiler-rt: MIT; Apache 2.0 with LLVM exception), and, where compressed files are read, zlib (HTSlib-based programs also bzip2 and liblzma). The licence texts of these libraries are in [assets/vendor/licenses/runtime-libraries/](assets/vendor/licenses/runtime-libraries/).

**Where the builds came from.** All programs except `diff` and `cmp`, the grep that carries out `grep -P`, and PLINK 2 are builds of the [Biowasm](https://biowasm.com) project, downloaded from `https://biowasm.com/cdn/v3/NAME/VERSION/` between 30 September and 10 October 2026 (each `NOTICE.txt` has the date). `diff` and `cmp` of GNU diffutils, and GNU grep 3.11 with PCRE2 10.42, were compiled with Emscripten for the course – `cmp` from its release source with a one-line patch, `diff`, grep and PCRE2 from theirs unchanged; they are not Biowasm builds. PLINK 2 comes from the [genomics-wasm](https://github.com/comparativechrono/genomics-wasm) project (commit `8eea96b`, its PLINK 2 port `d68433f`; its scripts: MIT): a development version of PLINK 2 of 12 October 2026, built without LAPACK with Emscripten 3.1.64 (with `-ffile-prefix-map`) and checked with the project's comparison suite against the native programs (41 of 41 cases); it runs as it was built, each command in a worker of its own (`assets/js/threads-worker.mjs`, adapted from genomics-wasm's runtime, MIT), with threads – which need a cross-origin isolated page. How each was built is in [assets/vendor/licenses/](assets/vendor/licenses/) (`diffutils-build/`, `grep-perl-build/`, `genomics-wasm-build/`). The Bioinformatics workbench bundles many more programs (read mapping, RNA-seq, single-cell, somatic and metagenomic analyses, peak calling, gene finding); this project leaves them out.

**Local changes** – all listed in [assets/vendor/biowasm/RUNTIME-PATCHES.txt](assets/vendor/biowasm/RUNTIME-PATCHES.txt):

- The JavaScript loaders of the programs record each program's exit status. The Aioli runner has two added methods: `execIO` runs a program with real standard input, output and error – and starts every program afresh for each run, as a process is on Linux –, and `statTree` lists the shared file system in one answer; [execio-source.txt](assets/vendor/biowasm/execio-source.txt) is their readable source.
- In each of the 17 **coreutils** programs and in **grep** 3.7, **one byte** of the `.wasm` file is changed, which makes the C library's standard output unbuffered. Unchanged, these builds lose output that does not end with a newline (`tr`, `head -c`, `fold` …; `grep -lZ`, `grep -z`). The byte, the reason and the checksums of the files as downloaded are in the [coreutils notice](assets/vendor/biowasm/coreutils/8.32/NOTICE.txt) and the [grep notice](assets/vendor/biowasm/grep/3.7/NOTICE.txt); the script that makes the change is [unbuffer-stdout.py](assets/vendor/licenses/local-patches/unbuffer-stdout.py).
- In the loaders of **date** and **gawk** the day of the year is counted in calendar days ([fix-day-of-year.py](assets/vendor/licenses/local-patches/fix-day-of-year.py)): as downloaded, `date -d 2024-07-15` printed “invalid date” in zones with summer time.
- All other `.wasm` and `.data` files from Biowasm are unmodified.

## Loaded at run time, not bundled

- **Pyodide 0.29.5** (MPL 2.0) – CPython 3.13 compiled to WebAssembly – is downloaded by the student's browser from the jsDelivr CDN (`https://cdn.jsdelivr.net/pyodide/v0.29.5/full/`) when a Python notebook is open (the page opens the last notebook the student had open, a Python one on the first visit), and then taken from the browser's cache. It provides CPython 3.13.2 (PSF licence) and the Pyodide builds of NumPy, pandas, Matplotlib, Biopython, SciPy, scikit-learn and the other packages a notebook imports, each under its own licence (see the [Pyodide package list](https://pyodide.org/en/stable/usage/packages-in-pyodide.html)). Packages installed with `%pip` come from PyPI. Spyder in the IDE tab runs the same Pyodide in a worker of its own, with Pyodide's builds of IPython 9 (BSD 3-Clause; its console) and jedi with parso (MIT; completion in its Editor).
- **webR 0.6.0** – R 4.6.0 compiled to WebAssembly – is downloaded from `https://webr.r-wasm.org/v0.6.0/` when an R notebook is open, R is first used in the terminal, or RStudio is opened in the IDE tab. The webR binaries are distributed under the GNU GPL 3 (R itself: GNU GPL 2 and 3); webR's JavaScript is MIT-licensed ([webR's licence notes](https://github.com/r-wasm/webr/blob/main/LICENSE.md)). R packages come from the site itself (locfit, above), the webR repository (`repo.r-wasm.org`) and r-universe (`bioc-release.r-universe.dev` – the current Bioconductor release, with DESeq2 (LGPL 3 or later) and edgeR (GPL 2 or later) –, `cran.r-universe.dev`, with downloads from `r2.ropensci.org`), each under its own licence.
- **Structures** come from RCSB PDB and AlphaFold DB; the **Databases** tab and code in notebooks use public web services (UniProt, EMBL-EBI – Europe PMC, ENA, InterPro, BLAST –, Ensembl, NCBI, RCSB PDB, AlphaFold DB), each under its own terms of use.
- The **AI assistant** sends a student's messages – and the agent its commands and their output – to the AI service the student chose, with the student's own key. No AI model or service is part of the site.
