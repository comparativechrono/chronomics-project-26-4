Up to now the project has been about a piece of DNA. This stage asks whether it does anything to the people who carry it – using studies of hundreds of thousands of people that are already done, already public, and sitting in your bundle.

You will learn
  • what GWAS summary statistics are and how to read a file of them

1. What is in these files

A genome-wide association study tests every common variant against a trait and publishes, for each, an effect size, its standard error and a P-value. Those summary statistics are public even when the individual data are not – which is why a student with a laptop can use a study of half a million people.

Eleven trait files. Note that the files do not share a column layout: one calls the position base_pair_location, another BP; one has beta, another LOGOR. Every one has to be read on its own terms.

Two ways to get a wrong answer that looks right

The build. Four of these files are on GRCh37 and two on GRCh38. Your variants are on GRCh38. At this locus the offset is 41,491 – you noted it in stage 1. Subtract it from a GRCh37 position to get GRCh38, and check your arithmetic by confirming that the alleles match.

The effect allele. A beta of +0.6 is meaningless until you know which allele it refers to. Every file names an effect allele and another allele; if the file's effect allele is your reference allele, the sign flips. Get this wrong and you will report that the haplotype shortens the PR interval when it lengthens it.

3. All 20 variants, all 11 traits

Now write it properly. The pattern – read a file, resolve its column names, convert the build, align the allele, keep the rows you want – is the single most reusable piece of code in genetics:

OFFSET <- 41491
hap <- read.delim("/data/examples/scn5a/annotation/haplotype_variants.tsv")
builds <- c(PR_interval_Ntalla2020 = 37, QRS_duration_Sieliwonczyk2025 = 37,
            QT_interval_Hoffmann2022 = 38, resting_heart_rate_Zhu2019 = 37,
            atrial_fibrillation_Yuan2025 = 38, brugada_syndrome_Barc2022 = 38,
            chronotype_Jones2019 = 37, morning_person_Jones2019 = 37,
            sleep_duration_Dashti2019 = 37, insomnia_Lane2019 = 37)

pick <- function(nms, want) { i <- which(tolower(nms) %in% want); if (length(i)) i[1] else NA }
lookup <- function(stem) {
  d <- read.delim(file.path("/data/examples/scn5a/gwas", paste0(stem, ".tsv")))
  n <- names(d)
  ci <- list(pos  = pick(n, c("base_pair_location", "bp", "pos")),
             ea   = pick(n, c("effect_allele", "allele1", "a1")),
             oa   = pick(n, c("other_allele", "allele0", "a0", "allele2")),
             beta = pick(n, c("beta", "logor")),
             se   = pick(n, c("standard_error", "logor_se", "se")),
             p    = pick(n, c("p_value", "p_bolt_lmm", "p")))
  stopifnot(!any(is.na(unlist(ci))))
  d$pos38 <- d[[ci$pos]] - ifelse(builds[[stem]] == 37, OFFSET, 0)
  m <- merge(hap[, c("pos_GRCh38", "rsid", "ref", "alt")], d, by.x = "pos_GRCh38", by.y = "pos38")
  flip <- toupper(m[[n[ci$ea]]]) == toupper(m$ref)       # effect allele is OUR reference: flip
  data.frame(trait = stem, pos = m$pos_GRCh38, rsid = m$rsid,
             beta = ifelse(flip, -m[[n[ci$beta]]], m[[n[ci$beta]]]),
             se = m[[n[ci$se]]], p = m[[n[ci$p]]])
}
res <- do.call(rbind, lapply(names(builds), lookup))
res$z <- res$beta / res$se
table(res$trait)
Check

A clean split

Cardiac conduction: four traits with P below 10−4, in the direction you would expect from a variant that reduces sodium-channel availability – a longer PR interval, a longer QT, higher Brugada risk. Circadian and sleep: nothing. The smallest circadian P-value is 0.11, which is what the best of eleven essentially random numbers looks like.

The split is worth stating carefully. These five circadian studies are large – the UK Biobank chronotype study has 450,000 people – so this is a reasonably powered null, not an absence of data. For a block sitting beside a cardiac ion-channel gene, that is the result you would predict. It is still worth having, because it was not obvious before you looked, and a published null is more useful to the next person than a silence.

4. Multiple testing, honestly

You have just done 20 × 11 = 220 tests. Correcting naively by 220 would be too harsh, because the 20 variants are nearly perfectly correlated – they are one haplotype, so they are close to one test, not 20 – and too lenient in another way, because you chose these traits after seeing the gene.

# how many independent variants are there, really?
sel <- match(hap$pos_GRCh38, pos)
sel <- sel[!is.na(sel)]
ev <- eigen(cor(t(H[sel, ])), only.values = TRUE)$values
sum(ev)^2 / sum(ev^2)        # effective number of independent tests
Check

The effective number of independent variants is close to 1. So the right correction is for the number of traits – eleven – giving a threshold of 0.05/11 = 0.0045. Four cardiac traits pass it; no circadian trait comes close.

Think

You have four P-values below 10−4 for a 50 kb haplotype beside a cardiac gene. What is the most likely reason that is not "this haplotype affects cardiac conduction"? You met the answer in stage 8 and it is the subject of stage 10 – but try to state the problem yourself before you turn the page.

Going further

  • Direction of effect. Are all 20 variants' betas the same sign within a trait? They should be, if they are one haplotype. Any that are not tell you about a lookup error or a phasing problem – find out which.
  • Forest plot. Plot beta with 95% confidence intervals for all 20 variants, faceted by trait. It makes the consistency – and the circadian nulls – visible at a glance.
  • More traits. The GWAS Catalog has thousands of studies with public summary statistics. Pick three more traits that you can justify before you look, and add them. Write down your prediction first.
  • How big is the effect? 0.64 ms of PR interval is the effect of carrying one copy. Put that next to the normal range of the PR interval and the threshold for first-degree AV block. Is this a difference anyone would notice?
