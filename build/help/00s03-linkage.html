2. The two-by-two table

Because the data are phased, each of the 5,008 chromosomes has a definite pair of alleles: one from each variant. Count the four combinations:

tab <- table(rs41310749 = a, rs41310239 = b)
tab
addmargins(tab)
Check

4,286 chromosomes carry neither, 163 carry rs41310749 alone, 26 carry rs41310239 alone, and 533 carry both.

What that table means

If the two variants were inherited independently, you would expect about 5,008 × 0.1390 × 0.1116 ≈ 78 chromosomes carrying both. There are 533. They are very far from independent.

But look at the 163 and the 26. If the two had truly never been separated, one of those cells would be empty. Neither is. "Complete linkage disequilibrium" is already in trouble – and in stage 6 you will find out which population those 163 come from.

3. D, D′ and r², by hand

Write pA for the frequency of the rs41310749 alternative allele, pB for rs41310239, and pAB for the frequency of chromosomes carrying both. The basic quantity is

D = pAB − pA pB

– how much more often the two travel together than chance would give. D is awkward on its own because its possible range depends on the frequencies, so it is scaled two ways. D′ divides by the largest value D could have taken; r² is the squared correlation between the two alleles.

pA <- mean(a); pB <- mean(b); pAB <- mean(a == 1 & b == 1)
D <- pAB - pA * pB
Dmax <- if (D >= 0) min(pA * (1 - pB), pB * (1 - pA)) else min(pA * pB, (1 - pA) * (1 - pB))
Dprime <- abs(D) / Dmax
r2 <- D^2 / (pA * (1 - pA) * pB * (1 - pB))
c(pA = pA, pB = pB, pAB = pAB, D = D, Dprime = Dprime, r2 = r2)
cor(a, b)^2          # r2 is just the squared correlation
Check

D′ = 0.946 and r² = 0.697. And cor(a, b)^2 gives exactly the same r² – the two formulas are the same thing.

Think

D′ near 1 says recombination has essentially never separated these two. r² of 0.7 says one is an imperfect proxy for the other. Both are true at once. Which of the two would you want to be high if you were choosing a variant to genotype as a stand-in for another? Which would you want if you were asking whether two variants arose on the same ancestral chromosome?

4. The same calculation, one population at a time

Make a function of what you just wrote, then apply it within each superpopulation. Each person contributes two consecutive alleles, so repeat each label twice:

ld <- function(a, b) {
  pA <- mean(a); pB <- mean(b); pAB <- mean(a == 1 & b == 1)
  D <- pAB - pA * pB
  Dmax <- if (D >= 0) min(pA * (1 - pB), pB * (1 - pA)) else min(pA * pB, (1 - pA) * (1 - pB))
  c(n = length(a), pA = round(pA, 4), pB = round(pB, 4),
    Dprime = round(abs(D) / Dmax, 3), r2 = round(D^2 / (pA * (1 - pA) * pB * (1 - pB)), 3))
}
samples <- read.delim("/data/examples/scn5a/1000g/samples.tsv")
sup <- rep(samples$superpopulation, each = 2)
length(sup) == length(a)
t(sapply(split(seq_along(a), sup), function(i) ld(a[i], b[i])))

In Europeans the two variants are the same variant for all practical purposes: r² = 1, every chromosome that has one has the other. In Africans D′ is still 1 – they have never been separated by recombination – but r² is 0.10, because rs41310749 is eight times commoner there than rs41310239.

The explanation

D′ = 1 with very different frequencies has one simple reading: the rarer allele arose on a chromosome that already carried the commoner one. Every copy of rs41310239-G sits on an rs41310749-A background, but not the other way round. The older allele is rs41310749-A; the younger one is rs41310239-G, and it arose later, on a subset of those chromosomes.

The 2012 study was of a single kindred – 22 mutation carriers – and within one family two variants this close together will almost always travel together. "Complete linkage disequilibrium" was a fair description of what they could see. It is not a property of the variants: it is a property of the sample they saw them in.
